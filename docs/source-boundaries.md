# Source Boundaries

This repository does **not** claim forensic reconstruction of John Whitney's machinery or films. It makes narrower claims:

- the sketches are grounded in documented Whitney concerns such as harmonic motion, cyclic point systems, visual music, phase offsets, and optical accumulation;
- the implementation is a modern browser system built for accessibility, reproducibility, and public study;
- provenance labels are part of the public contract and should not be diluted in README copy, social posts, or issue labels.

## Public language rules

- Say `historically grounded study` when a sketch is motivated by documented Whitney concepts or film descriptions.
- Say `Whitney-inspired study` when the work is interpretive rather than source-matched.
- Say `modern extension` when the method adds contemporary sampling, browser-specific rendering, or other non-historical techniques.
- Do **not** say `exact reconstruction`, `faithful remake`, or `Whitney's original algorithm` unless new evidence is added and cited directly.

## Current source basis

These are the sources that shape the repository framing:

- John Whitney, *Digital Harmony: On the Complementarity of Music and Visual Art*.
- *Experiments in Motion Graphics* as a workflow-adjacent audiovisual source.
- William Moritz's historical essay on Whitney as a computer animation pioneer.
- Public catalog descriptions of works such as *Catalog*, *Permutations*, *Matrix III*, and *Arabesque*.

The repo currently treats these as high-level grounding, not page-perfect reconstruction evidence.

## Asset policy

- No copyrighted Whitney film frames are checked into the repo.
- No scraped stills are used as hero images or thumbnails.
- Exported media in this repo must be generated from repository code.
